# Butinas Bar — site oficial

    npm install
    npm run dev      # desenvolvimento
    npm run build    # produção (pasta dist/)

Todo o conteúdo editável está em `src/data/site.ts`: contatos (WhatsApp, Instagram, endereço, horários), imagens, cardápio, galeria e agenda.
Coloque as fotos em `public/images/` e referencie como `"/images/arquivo.jpg"`. Pendências marcadas com `TODO` no arquivo.
